# Personal Finance Visualizer

## Overview

Personal Finance Visualizer is a web application designed to help you track, analyze, and optimize your personal finances with intuitive visualizations and comprehensive financial management tools.

## Features

- 📊 Transaction Tracking
  - Add, edit, and delete financial transactions
  - Categorize transactions for better insights
  - View transaction history

- 💰 Budget Management
  - Set monthly budgets per category
  - Compare budget vs. actual spending
  - Visual budget progress tracking

- 📈 Financial Insights
  - Monthly expenses bar chart
  - Category-wise spending pie chart
  - Dashboard summary cards

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Shadcn/UI
- Recharts
- React Query

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
